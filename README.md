# Forty Pixels

The Forty Pixels agency website, built with the standard Next.js App Router.

## Requirements

- Node.js 22 or newer
- npm

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Project structure

- `app/` — pages, shared components, layout, and global styles
- `public/` — brand assets, project logos, social preview, and site videos

The project has no database, API scaffold, Cloudflare Worker, Vinext runtime, or ChatGPT-specific integration.
